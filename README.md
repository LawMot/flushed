# 🚽 flushed

**The website for finding the best-rated public and private restrooms near you.**

## Features
- Account Creation and Log In
- Creating and Deleting Reviews
- Searching for Bathrooms and Reviews
- Gaining Experience Points and Ranking Up

## Deployment

### Start the Backend

```bash
cd backend
npm i
npm run start
```

### Start the Frontend

Open a second terminal and run:

```bash
cd frontend
npm i
npm run dev
```

### Open the Application

After both servers are running, navigate to:

```text
http://localhost:5173/
```
